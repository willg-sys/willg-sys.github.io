About This Project

I built this Ride Controller for Universal Creative using an ESP32 and FreeRTOS to make sure the emergency brakes are functional. To keep things safe, I put the braking logic on its own dedicated CPU core, so it never gets bogged down by the WiFi or web dashboard. I used AJAX polling and Mutexes to keep the data clean and the system stable. My timing logs show the brake task hits its 50ms deadline every time, leaving a huge safety margin to stop the ride instantly, no matter how much sensor spamming it takes.
